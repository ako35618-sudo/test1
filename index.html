1컴퓨팅 시스템이란?

컴퓨터는 정보를 받아서(입력) → 처리하고 → 결과를 보여 주는(출력) 기계예요. 만져 볼 수 있는 장치는 하드웨어, 장치를 움직이게 하는 프로그램은 소프트웨어라고 해요.

그림: 이 앱을 위해 AI가 새로 그린 도식(창작)이에요. 화살표는 데이터가 오가는 방향을 보여 줘요.

스마트폰, 태블릿, 키오스크도 모두 컴퓨팅 시스템입니다.

CPU·RAM·SSD 그림은 실제 부품의 대표적인 모양을 생각해 AI가 새로 그린 도식(창작)이며 사진이 아니에요. 실제 부품은 제품마다 모양이 달라요.

구분역할예
입력장치데이터를 컴퓨터에 넣음키보드, 마우스, 마이크, 터치스크린
중앙처리장치(CPU)명령을 해석(제어장치)하고 계산(연산장치)함 — 컴퓨터의 두뇌CPU
주기억장치실행 중인 프로그램·데이터를 잠시 저장. 속도 빠름, 전원이 꺼지면 내용이 사라짐(휘발성)RAM
보조기억장치프로그램·파일을 오래 저장. 전원이 꺼져도 유지됨SSD, HDD, USB
출력장치처리 결과를 사람에게 보여줌모니터, 스피커, 프린터

5운영체제(OS)의 기능

운영체제는 사용자·응용 프로그램·하드웨어 사이를 이어 주는 관리자예요. 교통 정리를 하는 안내원처럼, 여러 프로그램이 부딪히지 않게 자원을 나눠 줘요.

그림: AI가 새로 그린 도식(창작)

기능쉬운 설명
프로세스(CPU) 관리여러 프로그램이 CPU를 번갈아 쓰도록 순서를 정해 줌
메모리 관리프로그램마다 주기억장치의 공간을 나누어 주고 회수함
파일(저장장치) 관리파일과 폴더를 만들고, 찾고, 지우는 일을 도움
입출력장치 관리키보드·프린터 같은 장치를 프로그램이 쉽게 쓰도록 연결함
사용자 인터페이스 제공사용자가 컴퓨터를 조작하는 방법을 제공: GUI(그림·아이콘·마우스), CLI(글자 명령어)

※ 교과서(출판사)마다 운영체제 기능을 묶는 방식과 용어가 조금씩 달라요. 수업에서 쓰는 교과서의 표현과 비교해 확인하세요.

한눈에 정리

입력 → (보조기억장치에서 주기억장치로 불러옴) → CPU 처리 → 출력 / 이 모든 과정을 운영체제가 관리한다.

※ 이 앱의 설명·비유·그림·퀴즈 문항은 AI가 성취기준에 맞춰 새로 만든 것으로, 특정 교과서의 원문이나 사진이 아닙니다(창작 내용). 사용 전 교사가 교과서와 대조해 검토해 주세요.
